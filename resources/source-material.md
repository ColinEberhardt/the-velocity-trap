# Source material

Everything the plot, dialogue, and mentor-figure teaching should trace back to — real practitioner input and Colin's own published thinking, not invented tensions.

## Practitioner interviews

Source material not carried into this repo — a ~61-minute recorded discussion with Scott Logic consultants (Adam Thomas, Ollie Southwell, Sam Hobbs, Tom Pearson, Tim Johnson, facilitated by Colin) describing live AI-assisted delivery on three different client engagements, plus a facilitator's three standing questions (impact today / impact in future / what should the company do). Held in a separate, internal `ai-sdlc/interviews/` directory outside this project.

Named files, for reference (not included here):

- `discussion_processed-transcript.md` — full cleaned transcript, named speakers, timestamps (preferred for quotes/attribution)
- `discussion-themes-attendees.md` — themes drawn only from attendees (excludes Colin's facilitation) (preferred for quotes/attribution)
- `discussion-summary.md` — older anonymized version, organised by the three questions asked
- `discussion-themes.md` — older anonymized version, the same material re-cut by theme

See [`themes-to-dramatize.md`](themes-to-dramatize.md) for the resulting list of themes the plot needs to hit.

## Colin's own published thinking

- `the-future-of-software-development.md` — Markdown copy of Colin's presentation "The Future of Software Development" (SharePoint, HgCapitalJumpStartProgramme site). Lays out a set of named principles (Shaping Systems over Writing Code, Product Thinking over Delivery Thinking, Validating Outcomes over Reviewing Code, Fast Feedback over Upfront Certainty, Breadth of Perspective over Narrow Specialism, Empowered Individuals over Bloated Teams, Contextual Judgement over Standardised Process, Continuous Transformation over One-Time Change) — this is a strong, near-ready-made candidate for the book's closing "distilled framework," since it already independently converges on several of the same conclusions as the interviews (small empowered teams, validation over review, product/outcome focus over delivery speed).
- [`newsletter-themes.md`](newsletter-themes.md) — themes distilled from all 60 issues of Colin's weekly newsletter, *Augmented Coding Weekly* (a separate `augmented-coding-weekly` repo, not included here; issues run July 2025–September 2026). Unlike the interviews (a snapshot from five people at one moment) or the presentation (a single point-in-time framework), this is a 14-month longitudinal record of Colin's own published thinking as the industry moved — several themes there sharpen or add new material to [`themes-to-dramatize.md`](themes-to-dramatize.md) (security/safety risk, open source under strain, and a "software for one" positive counter-thread all first appear here).
